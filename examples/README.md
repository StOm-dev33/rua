# Examples

Set up a [station with a physical arm](../docs/getting-started.md), then choose
an example to control the arm or run an agent. Use [MuJoCo](../docs/simulation.md)
to test without hardware.

| Example | What to try |
| --- | --- |
| [Python](python/README.md) | Read arm state, preview a move, or run a model-driven loop. |
| [TypeScript agent](typescript/agent/README.md) | Run the reference agent from the terminal or import its loop. |
| [Optional viewer](../docs/install-from-source.md#optional-viewer) | Control the arm manually, run tasks, connect cameras, and review recordings. |
| [Example applications](applications/README.md) | Inspect blocks or answer questions about an image using the wrist camera. |
| [MuJoCo](mujoco_sim/README.md) | Run a simulated station with one or two SO-101 arms. |

See [Write your own loop](../docs/write-your-own-loop.md) when you’re ready to
adapt an example.
